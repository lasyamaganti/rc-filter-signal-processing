# RC Filter Signal Processing

A MATLAB project exploring **RC circuit modeling, frequency response, and signal filtering** using differential equations and transfer functions. The project applies these concepts to both circuit analysis and audio noise reduction.

## Project Overview

- Modeled RC circuits using differential equations and MATLAB
- Analyzed low-pass, high-pass, and cascaded RC filters
- Evaluated magnitude and phase responses across different frequencies
- Designed a filter to attenuate a 100 kHz signal while preserving a 50 Hz signal
- Used power spectral density analysis to identify noise in an audio recording
- Designed and simulated a cascaded filter to reduce 60 Hz hum and high-frequency noise

## Technologies & Concepts

**MATLAB • Signal Processing • RC Circuits • Differential Equations • Transfer Functions • Frequency Response • Filter Design**

## Key Results

The designed low-pass filter preserved approximately **95.4% of the 50 Hz signal amplitude** while reducing the 100 kHz component to approximately **0.159%**. The audio filtering application also reduced 60 Hz hum and high-frequency noise identified through power spectral density analysis.
